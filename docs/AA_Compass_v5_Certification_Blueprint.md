# A&A Compass v5 - Certification Blueprint

## Certification name
A&A Compass Certified Alignment Coach

## Positioning
This is a proprietary coaching-method certification for the A&A Compass system. It is not a therapy license, financial advisor license, medical credential, legal credential, or ICF credential.

## Public pricing
Certification is not a fourth public tier. It is a Pro-only pathway.

## Certification access
Pro users may apply. They do not automatically receive the credential.

## Requirements
1. Active Pro subscription.
2. Application and purpose statement.
3. Identity verification.
4. Ethics agreement.
5. Completion of training modules.
6. Passing written assessment.
7. Passing practical coaching simulation.
8. Supervised practice review.
9. Approval by admin.
10. Credential issuance with ID and QR verification.

## Anti-duplication design
- Each certificate has a server-generated credential ID.
- Each credential has a QR code linking to /certification/verify/[credentialId].
- Public verification page shows: name, credential status, issue date, renewal date, scope, and revocation status.
- Certificate PDF includes credential ID, signature block, verification URL, and non-transferability notice.
- Admin can revoke or suspend credentials.
- Credential events are stored in an audit log.

## Assessment rubric
- Understands 6A Engine.
- Reflects truth without judgment.
- Connects belief to action.
- Avoids guarantees and blame.
- Protects user autonomy.
- Uses service/increase-life outcome.
- Knows when to refer out to professionals.
- Maintains confidentiality.
- Does not create dependency.

## Renewal
- Annual renewal.
- Ethics recommitment.
- Short renewal assessment.
- Evidence of continued practice.

## Revocation triggers
- False income claims.
- Misrepresenting the credential as therapy/license.
- Selling guaranteed outcomes.
- Breaching confidentiality.
- Harassment, manipulation, or coercive spiritual claims.
- Using the certificate after expiration.
