# A&A Compass v5 Static App Prototype

Open `index.html` in a browser. This prototype demonstrates the final launch tiers:

- Free: one daily Compass Reading, browser-native voice utility where supported.
- Plus: $19/month, unlimited/saved/deeper plans in production.
- Pro: $99/month, premium A&A Aligned Voice Coach and certification pathway in production.

This is a no-backend prototype. In production, Stripe and server-side entitlements must control access.
