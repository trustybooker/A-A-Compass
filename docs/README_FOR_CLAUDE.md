# A&A Compass v5 - Production Package for Claude

This package contains the full launch direction, tier access rules, certification system, voice architecture, skill prompt, training material, slide deck, static prototype, and production build instructions.

## Final public tiers
- Free: $0
- Plus: $19/month
- Pro: $99/month

There are exactly three public tiers at launch. Certification is not a fourth public tier. It is a gated pathway inside Pro and requires approval.

## Core outcome standard
Every session must produce:
1. Truth reflection
2. Deeper value
3. Misalignment/pattern to release
4. Definite vision
5. One grounded action
6. One habit loop
7. One gratitude anchor
8. One service/increase-life action
