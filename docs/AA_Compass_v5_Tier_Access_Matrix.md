# A&A Compass v5 - Tier Access Matrix

## Pricing
- Free: $0
- Plus: $19/month
- Pro: $99/month

## Access by feature
| Feature | Free | Plus $19 | Pro $99 |
|---|---:|---:|---:|
| Daily typed Compass Reading | 1/day | Unlimited | Unlimited |
| 6A Engine result | Yes | Yes | Yes |
| Browser speech-to-text | Utility only | Utility + saved | Utility + saved |
| Browser read-aloud | Utility only | Saved listen mode | Saved listen mode |
| Premium A&A Aligned Voice Coach | No | No | Yes |
| Smart follow-up questions | Limited | Guided form | Realtime voice + AI |
| Saved cloud history | No | Yes | Yes |
| Streaks and habit tracking | Basic/local | Yes | Yes |
| 7-day plan | Basic | Yes | Yes |
| 30-day plan | No | Yes | Advanced personalized |
| Weekly pattern report | No | Basic summary | Advanced coach report |
| Export readings | No | Yes | Yes |
| Advanced modes | No | Some | All |
| Certification pathway | No | No | Eligible only; not automatic |
| Credential verification | No | No | For approved certified coaches |

## Free should access
- First outcome.
- One meaningful daily result.
- Browser voice sample with honest limitation notice.

## Free should not access
- Unlimited sessions.
- Cloud history.
- Premium aligned voice.
- Weekly reports.
- Certification.

## Plus should access
- Consistency and history.
- Saved plans, reminders, exports.
- Better daily value without realtime Pro voice.

## Plus should not access
- Premium realtime voice coach.
- Certification pathway.
- Advanced supervised coaching tools.

## Pro should access
- Full transformation system.
- Premium voice coach.
- Pattern memory and weekly reports.
- Certification pathway eligibility.

## Pro should not automatically access
- Certification credential.
- Ability to train/certify others.
- Admin verification tools.
- Public credential until approved.
